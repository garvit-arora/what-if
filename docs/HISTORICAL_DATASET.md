# Historical dataset

Version `napoleonic-europe-1.0.0` contains 22 curated events (1789–1848), four people, four institutions, four places, five sources, and five causal mechanisms. Stable Wikidata identifiers provide entity/date provenance; institutional and reference sources support the reviewed narrative context.

The source file is `data/seeds/napoleonic_history.json`. Event chronology is represented with `PRECEDED` only and never treated as causation. Mechanisms are separately labeled `documented` or `model_assumption`.

Primary reviewed sources include Wikidata, Encyclopaedia Britannica, and the Château de Versailles institutional history pages. The seed records direct URLs. This is a curated demonstration graph, not a comprehensive history of Europe.
